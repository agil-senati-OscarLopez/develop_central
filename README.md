   # Prácticas Ágiles - SENATI

   Aplicación web de apoyo al curso de Gestión de Proyectos de Software.

   ## Archivos
   - index.html: estructura de la página.
   - script.js: lógica del tablero Kanban.
   - styles.css: estilos visuales.

   ## Cómo usarla
   Descarga los tres archivos en una misma carpeta y abre index.html en el navegador.
